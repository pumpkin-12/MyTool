## Bug 修复：题库切换题型白屏

**症状**：刷题 → 题库 → 点其他题型 tab，面板整块空白（只剩主标签）。

**根因**：主标签与题库题型标签**共用 class `qz-tab`**。`render()` 用 `root.querySelectorAll('.qz-tab')` 统一绑 `setTab(b.dataset.tab)`，题库题型按钮只有 `data-bank-tab`、没有 `data-tab`，于是点它时第二个监听器执行 `setTab(undefined)` → `tab=undefined` → render 的 if 链无匹配分支 → `[data-panel]` 留空 = 白屏。（绑定时序：bindBank 的处理器先跑并 render，随后旧按钮上的 `.qz-tab` 处理器仍会触发，覆盖 tab。）

**修复**（`render()` 内）：
- 选择器限定 `.qz-tab[data-tab]`，只绑主标签。
- 加防御：`render()` 开头 `if (['dash','quiz','bank','wrong','records','stats'].indexOf(tab)<0) tab='dash';`，未知 tab 回落仪表盘，杜绝再白屏。

**这是既有隐性 bug**，与第 1 档功能/优化无关（`.qz-tab` 共用类从一开始就在）。

验证：语法 0 错误；quizcore 87/0；appstore 35/0；无残留裸 `.qz-tab` 选择器。`index.html` 220 KB / 4909 行。
